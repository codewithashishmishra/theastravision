Application-Layer E2EE

Encrypted Before It Leaves the Server

Every JSON API response is wrapped in AES-256-GCM after an ECDH P-256 handshake. Decryption keys live only in browser memory—never in localStorage—so XSS cannot steal long-lived secrets.

1

ECDH Handshake

Client and server exchange ephemeral P-256 public keys and derive a shared AES-256 session key via HKDF—never transmitted on the wire.

2

Encrypted JSON Payload

Sensitive HR, payroll, and careers data is encrypted at the application layer with unique IVs, nonces, and sequence numbers for replay protection.

3

In-Memory Decrypt

The admin portal and careers site decrypt via native Web Crypto (hardware-accelerated AES-NI)—typically under 5 ms per response with zero perceptible UI delay.
